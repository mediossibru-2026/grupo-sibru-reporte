GRUPO SIBRÜ - Corrección de IDs inválidos
Problema detectado: Los códigos 019835/4 y 020919/0.5 contienen el carácter / que no es válido como ID en Firestore.

Solución: Se guardarán con IDs alternativos válidos, manteniendo el código original como campo de búsqueda.
Cambios de ID:
019835/4 → 019835-4 (Salsa BBQ Original)
020919/0.5 → 020919-05 (Salsa Mango Habanero)
